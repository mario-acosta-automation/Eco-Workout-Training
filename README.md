# EcoWorkout · CV Digital - Adriana Castañeda

CV digital profesional de Adriana Castañeda García, entrenadora personal especializada en cultura física y deporte.

## Características
- Diseño moderno y responsive.
- Header fijo con navegación suave y menú hamburguesa.
- Sección de eco workout dinámicos desde Google Sheets.
- Línea de tiempo vertical para experiencia profesional.
- Certificados con iconos representativos.
- Carrusel de competencias deportivas con imágenes.
- Integración con redes sociales (Instagram, LinkedIn, Superprof).
